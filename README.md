# Smash Karts Ultra-PBR (Cloud APK Build — No Android Studio Needed)

## Option 1: Free Cloud APK Build via GitHub Actions (Zero Install)
1. Create a free repository on [GitHub](https://github.com/new).
2. Unzip `SmashKartsAndroid.zip` and upload all files inside `SmashKartsAndroid/` (including the `.github/` folder) to your repo.
3. Open the **Actions** tab on GitHub — the **Build Android APK (Cloud)** workflow runs automatically and produces a downloadable **SmashKarts-PBR-APK** (`app-debug.apk`) in ~2 minutes. Transfer `app-debug.apk` to your phone and install!

## Option 2: Build Locally in Android Studio
Open the `SmashKartsAndroid` folder in Android Studio and click **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
